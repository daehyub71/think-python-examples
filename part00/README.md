# 생각하는 파이썬 Part 0 · 시작하기 전에 — 예제 소스

강의에 나온 코드를 그대로 실행해 볼 수 있게 파일로 모았습니다.

- 실행: 이 폴더에서 `python3 파일이름.py` (Windows 는 `python 파일이름.py` 또는 `py 파일이름.py`)
- 대화형 모드(`>>>`)에서 식만 쳐서 보던 것은, 파일에서는 `print()` 로 감싸 두었습니다.
- ⚠️ 표시가 있는 파일은 **일부러 오류가 나게** 만든 것입니다. 오류 메시지의 마지막 줄을 읽어 보세요.

| 파일 | 내용 |
|---|---|
| `01_average.py` | 세 과목 평균 — 파이썬이 읽기 쉬운 언어라는 예 |
| `02_repl_practice.py` | 대화형 모드에서 쳐 본 계산들을 한 파일로 |
| `03_hello.py` | 첫 프로그램 — 파일로 저장해 실행하기 |
| `04_welcome.py` | 두 줄짜리 프로그램 — 변수와 문자열 잇기 |
| `05_error_paren.py` | ⚠️ 일부러 틀린 코드 — 괄호를 닫지 않으면 |
