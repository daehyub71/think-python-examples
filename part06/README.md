# 생각하는 파이썬 Part 6 · 객체로 세상을 모델링하기 — 예제 소스

강의에 나온 코드를 그대로 실행해 볼 수 있게 파일로 모았습니다.

- 실행: 이 폴더에서 `python3 파일이름.py` (Windows 는 `python 파일이름.py` 또는 `py 파일이름.py`)
- 오류를 보여 주는 줄은 주석으로 막아 두었습니다. 주석을 풀어 오류 메시지를 직접 확인해 보세요.
- 영상의 「실습」 화면에서 쓴 코드는 `실습/` 폴더에 있습니다.

| `08_operators.py` | 연산자도 메서드다 — __add__ · __eq__ · __lt__ |
