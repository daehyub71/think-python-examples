# 생각하는 파이썬 Part 10 · 동시에 여러 일 하기 (병행·병렬 · GIL · 스레드 · 프로세스) — 예제 소스

강의에 나온 코드를 그대로 실행해 볼 수 있게 파일로 모았습니다.

- 실행: 이 폴더에서 `python3 파일이름.py` (Windows 는 `python 파일이름.py` 또는 `py 파일이름.py`)
- 화면에 찍히는 **시간은 컴퓨터마다, 실행할 때마다 다릅니다.** 볼 것은 숫자가 아니라 "줄었는가, 그대로인가"입니다.
- 스레드가 찍는 줄의 **순서도 실행마다 달라질 수 있습니다.**
- `work.py`(계산 함수)와 `team.py`(스레드를 만들고 기다려 주는 함수)는 다른 예제가 불러다 쓰는 파일입니다. 같은 폴더에 두세요.

| 파일 | 내용 |
|---|---|
| `01_one_by_one.py` | 기다리는 일 세 개를 순서대로 — 3.0초 |
| `02_threads.py` | 같은 일을 스레드 셋으로 — 1.0초 (`Thread` · `start` · `join`) |
| `03_cpu_threads.py` | 계산하는 일에 스레드를 쓰면 — 시간이 거의 그대로 |
| `04_race.py` | 같은 변수를 함께 고치면 값이 사라진다 — 300 이 아니라 100 |
| `05_lock.py` | `Lock` 으로 한 번에 한 스레드만 — 300 |
| `06_process.py` | 프로세스는 변수를 따로 가진다 · `__main__` 가드 |
| `07_pool.py` | `Pool` 로 계산을 나눠 주기 — 시간이 줄어든다 |
| `work.py` · `team.py` | 위 예제들이 불러다 쓰는 파일 |
| `practice_answers.py` | 직접 해보기 풀이 (다 도는 데 30초쯤 걸립니다) |
| `실습/` | 영상의 실습 화면에서 실행한 파일(L01~L05) |
